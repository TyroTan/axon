# Track 1 — ML Fundamentals · ML Math Theory · RAG Architecture · LLM Systems

## What this track covers

| Major branch | Focus |
|---|---|
| ML Fundamentals | Supervised learning, loss functions, gradient descent, regularization, evaluation |
| ML Math Theory | Calculus for ML, linear algebra, probability, information theory, optimization |
| RAG Architecture | Embeddings, chunking, retrieval, re-ranking, graph traversal, context budget |
| LLM Systems | Context windows, tokenization, system prompts, tool use, agentic loops, fine-tuning vs RAG |

## Why this combination

These four branches are tightly interdependent. You cannot reason about RAG quality
without understanding embedding geometry (Math Theory). You cannot design agentic
retry logic without understanding state machine failure modes (LLM Systems × ML Fundamentals).
The cross-branch questions are where the most valuable learning happens.

## External context sources

This track (specifically, the first session) derived its starting profile from external
`.md` files outside `.experiments/`. These are listed in `context/_sources.md` and
snapshotted in `context/`. Subsequent tracks (`track_1_2` onward) use snapshots only —
no external file dependencies.
